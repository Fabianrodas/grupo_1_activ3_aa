# Gestor de tareas con análisis de rendimiento
Este es un proyecto que te ayudará en organizar tus tareas basados en distintos criterios que se pueden seleccionar acorde a la situación, como lo es:
- **Nombre**
- **Fecha de vencimiento**
- **Nivel de prioriodad**

Una vez introduzcas las tareas que desees (10 tareas en total), deberás introducir el criterio por el cual desees ordenar y luego te las va a ordernar.

## Objetivo del programa

Aparte de servir como un organizador de tareas, su función principal radica en demostrar el rendimiento de 3 importantes algoritmos de ordenamiento (Bubble Sort, Insertion Sort y Selection Sort) y realizar una comparativa real basado en la máquina local donde se está ejecutando el proceso.

Con esto podrás ver gráficamente un analisis y un "BenchMark"  de estos 3 algoritmos y cuales tienen mejores tiempos de ejecución basado en los distintos casos que se pudieron presentar en tus tareas.

## Instalación y uso

Para el uso del programa, necesitarás instalar algunas librerías importantes antes de poder ejecutarlo, por ello creamos un archivo `requirements.txt` donde encontrarás las librerías necesarias que deberás tener en tu máquina para poder ejecutar el programa correctamente.

### Pasos a seguir para ejecutar el organizador de tareas

1. Abre el simbolo de sistemas en tu computadora (CMD).
2. Accede a la carpeta donde está alojado el proyecto.
3. Una vez dentro, ejecuta la siguiente linea `pip install -r requirements.txt`
4. Espera a que termine de instalarse todas las dependencias y ya podrás ejecutarlo normalmente!

> Nota: Existen 2 formas actuales para poder ejecutar el programa, uno es el archivo `main_consola.py` el cual es una versión más ligera del sistema hecho únicamente en consola y el archivo `app.py` el cual ya usa una librería para hacer el apartado visual del programa.
